# Learn Go With Tests — решения и реализации

Репозиторий с моими решениями и реализациями из курса **Learn Go With Tests**.  
Курс сфокусирован на принципах **Test-Driven Development (TDD)** и практическом изучении языка **Go** через написание тестов.

## 🎯 Чему я научился

- Методологии разработки через тестирование (**TDD**)
- Вспомнил и углубил основы языка **Go**
- Написанию чистого, поддерживаемого и расширяемого кода
- Созданию комплексных и читаемых тестов
- Новым практикам и подходам к проектированию кода
